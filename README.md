## ✨ Features

### 📊 Dashboard
- Live KPIs: overall attendance, safe-to-skip / recovery status, pending assignments, active to-dos
- Today's classes with one-tap **Present / Absent / Cancelled** (tap again to undo)
- Per-subject health bars colour-coded against each course's target

### 📚 Subjects
- Course catalog with code, credits, faculty, room, colour tag and target attendance %
- Colours sync across charts, calendar and timetable
- Deleting a subject cleans up its slots, attendance and exams

### 🗓️ Timetable
- Weekly grid and daily agenda views
- Weekly, biweekly and one-time sessions: Lecture, Lab, Tutorial, Seminar, Workshop
- Automatic overlap and conflict detection
- 12-hour / 24-hour time display

### ✅ Attendance Center
- Log today or any past date, plus extra / make-up sessions with notes
- **Safe-to-miss buffer** and **recovery streak** calculated exactly
- **What-if simulator**: attend X classes, skip Y, see the projected %
- **Backfill past totals** for mid-semester onboarding
- Editable session history; cancelled classes never lower your percentage

### 📝 Exams & Marks
- Upcoming exams with live day countdowns
- Quiz, Unit Test, Midterm, Lab Practical, Viva, End-Term and custom categories
- Raw aggregate score and **weighted course score** per subject and across the semester

### 📓 To-Do Notebook (Kanban)
- Spiral-bound notebook with multiple pages and To Do / In Progress / Done columns
- Priorities, due dates and subject tags
- Ruled, grid, dot and plain paper, washi tape, scribble canvas, polaroid attachments
- One-click **Sync Assignments** without duplicates
- Import / export notebooks as JSON

### 📌 Assignments
- Homework, Project, Lab Report, Quiz, Presentation and Essay types
- Due date and time, priority levels, completion % and status filters

### 🏖️ Holidays
- Single and multi-day breaks: National, Institutional, Semester Break, Exam Prep, Personal
- Optionally **auto-suspend classes** so holidays never trigger false attendance warnings
- Scan a holiday circular from PDF, screenshot or `.ics`

### 📅 Unified Calendar
- Classes, exams, deadlines, holidays and attendance in one monthly grid
- Mark or edit attendance right from the day agenda
- **Export `.ics`** for Google Calendar, Apple Calendar and Outlook

### 📥 Universal File Importer
- In-browser parsing of `.xlsx`, `.xls`, `.ods`, `.csv`, `.tsv`, `.ics`, `.docx`, `.pptx`, `.odt`, `.html`, `.zip` and `.json` backups
- Optional AI vision scan for scanned PDFs and timetable photos
- Preview table with conflict badges, and select exactly which rows to import

### 📈 Analytics
- Credit-weighted attendance averages
- Course risk distribution: Healthy, Borderline, Critical
- Weekday lecture load and assignment completion charts

### 🎨 Appearance & Personalisation
- Interactive **3D Mars** landing page and **3D Black Hole** workspace
- Or use your own **custom background photo**
- Glassmorphism with live sliders for opacity, frost blur, photo dimmer and soft focus
- 10 accent presets or any custom hex, with automatic WCAG-safe button text

### 🔐 Privacy & Security
- **Local-first**: all data stays in your browser and works offline
- Salted, iterated SHA-256 hashing for passwords and recovery answers
- Friend's Name recovery with a Student ID fallback
- Isolated data per user on shared browsers
- Clean JSON backups that never include credentials

### 🚀 Quick Start
- **Instant Demo** mode with a pre-filled workspace, no sign-up needed
- 4-step onboarding wizard for new accounts
- Portable one-click JSON backup and restore
